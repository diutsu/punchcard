# planning-horizons plugin (draft 0.1)

Skills for writing and reviewing planning documents with the Planning Horizons model, and for editing technical prose in the author's house style.

| Skill | Use it to |
| --- | --- |
| `technical-writing` | Draft or rewrite technical prose in the house style (full guide in `references/style-guide.md`) |
| `editorial-review` | Critique a rant or draft, research support and rebuttals, then produce an edited draft with editor notes |
| `horizon-templates` | Pick the right horizon and fill its template (Vision, Target architecture, Discovery; Plan and Technical design pending) |
| `horizon-review` | Lint a document statement by statement, test its constraints, and check it against the documents above and below |
| `review-comment-coach` | Keep review comments at the document's horizon, for reviewers and for authors triaging them |

## Sources of truth

The skills' references are copies taken on 2026-11-11 from:

- the Planning Horizons paper (model summary in `skills/horizon-templates/references/model.md`),
- "Planning Horizons — templates (draft)" (one file per template),
- "Writing style guide".

When those docs change, refresh the copies. The paper wins over the summary where they disagree.
